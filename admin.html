Send test picks email
Emails a real, working picks link to your own admin address (yeti@yetiblanc.com) as whichever team you pick below — always your inbox, never a real family member, no matter what's selected. Use "preseason-3" for week to test safely against real live data with zero effect on real scoring; a real numbered week (1-18) plugs into real standings once picks are saved against it, so only use one of those once you actually mean to test against the live season. These are two separate buckets that never mix — a pick saved against "preseason-3" shows up on the Preseason Games tab but will NEVER appear on the Commissioner Portal's Missing Picks tracker (which only ever looks at real numbered weeks), and vice versa. If you're testing the Missing Picks tracker specifically, use a real week number here, not "preseason-3."

Manually trigger a poll
Forces an immediate Big Balls (regular season) + Highlightly (preseason) fetch-and-publish cycle right now, bypassing the normal polling windows/cadence entirely — useful to pull fresh scores on demand instead of waiting for the next scheduled tick. Each click is a real API call against both providers' own daily budgets (Big Balls 2000/day, Highlightly 100/day), so use this deliberately, not as a casual refresh button.

Built for resetting preseason test data before a clean multi-person test, but works on any week — remove this button yourself before opening the site for real regular-season picks.
